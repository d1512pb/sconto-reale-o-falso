Cómo replicarlo para otros productos

  1. Haz fork del repositorio y define tu lista de productos y fuentes en config/.
  2. Corre los colectores (localmente o con GitHub Actions) y el ETL: python -m sconto.mart.
  3. Entrena y evalúa por años: python -m sconto.modelo_final.
  4. Publica la app (python -m sconto.publicar_web) y, si quieres servicios en línea, la API con fly deploy (~US$2.5/mes).
